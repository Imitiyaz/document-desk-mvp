## 0.3.8 — Initial public release

Document Desk MVP is a local, single-user assistant for supported Excel and PDF documents.

- Native Windows setup and local Docker Compose deployment, with a separate host Ollama service.
- Original source records, spreadsheet-cell references and PDF page/table provenance.
- Supported exact calculations, complete selected populations and explicit missing/absent/zero handling.
- Bounded follow-up conversations and separate New chat, Remove document and Reset workspace actions.
- A desktop question-and-evidence workspace, synthetic examples and optional screenshot tooling.
- Developer guides, architecture diagrams, API contracts, tests, backup/restore utilities and AGPL source/license notices.

See [supported scope](docs/acceptance.md), [verification](docs/validation.md) and [limitations](docs/limitations.md). This learning MVP does not establish universal answer accuracy, a hardware capacity guarantee or a hardened multi-user service.
